💰 Pricing Plans & Feature Comparison Table

A clean and responsive Pricing Plans & Feature Comparison Table built with HTML5 and CSS3. The project displays three pricing plans — Basic, Pro, and Enterprise — along with a detailed comparison table of their features.

✨ Features
💳 Three pricing plans:
Basic — $9/mo
Pro — $19/mo
Enterprise — $49/mo
📦 Different storage options for each plan.
👥 Different user limits for each plan.
📧 Email Support comparison.
⚡ Priority Support comparison.
🕐 24/7 Dedicated Support comparison.
📊 Feature comparison table.
📱 Responsive layout using CSS Flexbox.
🎨 Clean and modern card-based UI.
🌈 Hover effect for buttons.
🖥️ Works on desktop, tablet, and mobile devices.
